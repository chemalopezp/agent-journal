# Strava / Google Health (planned)

- **Access:** personal health data needs the person's own consent (a user login), not a shared folder. Options: Strava's API with a personal app and a refresh token kept in a password manager; or periodic exports (Strava bulk export, Google Takeout) into Drive, read through google-drive.
- **What's new:** activities, sleep and steps since `last_run`.
- **Keep:** weekly summaries in the run's report, `sensitive: true`. Recommendations only.
