# Slack

- **Access:** the Slack connector. Read-only unless the person asks to post a specific message.
- **What's new:** messages in the run's channels since `last_run`, **including new replies on older threads** (check threads whose latest reply is newer than the last run). Mentions and DMs: search for the person's user ID.
- **Keep:** people and org changes as log lines on the person or org record, requests to the person as tasks. Never copy whole threads; link them.
- **Limits:** surface only what the run's lens asks for; never summarize a whole channel.
