# Gmail

- **Access:** the Gmail connector. Read-only by default; drafts only when the run lists `prepare`; never send.
- **What's new:** messages matching the run's query (e.g. unread, starred, a label) newer than `last_run`.
- **Keep:** requests → tasks; bills and renewals → tasks with due dates; dated things → events; statements and receipts → document cards (instructions/documents.md).
- **Limits:** never quote sensitive content (money, health, family) outside the vault.
