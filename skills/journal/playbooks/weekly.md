# Weekly run

Its own scheduled run (e.g. Friday at noon). `_every-run.md` first. Create `journal/weekly/YYYY-Www.md` from `_templates/weekly.md` if missing; write only in the agent section.

- **Quarter focus check:** progress on each item.
- **Wins, slipped, noise.**
- **Decisions this week** (links to each scope's `decisions/`).
- **New scope?** If several items over 2+ weeks don't fit any scope, suggest one (or a sub-scope), with the evidence. Never create it without the human's OK.
- **Habits:** streaks and misses from the daily checkboxes.
- **Balance** (optional): planned vs actual per active area, marked as an estimate.
- **Loose ends** to close before the weekend (max 3), and **next week's focus** (max 3).
