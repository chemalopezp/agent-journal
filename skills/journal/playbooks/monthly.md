# Monthly run

Its own scheduled run (e.g. the 1st at midnight; the morning run links it). `_every-run.md` first. Create `journal/monthly/YYYY-MM.md` for the month that ended; write only in the agent section.

- **Goals:** status of each active goal and the quarter focus; flag no progress all month.
- **Yearly goals:** what moved in `personal/goals/yearly-goals.md`.
- **Numbers:** habits by week, anything the human tracks.
- **Double down / drop:** one suggestion each.
- **Finances** (optional, with a finance connector): spending vs last month, anything unusual, upcoming renewals. Always private: never in notifications.
